# Simple Interest Calculator

A calculator that computes the Simple Interest on a principal amount over a given time at a specified rate of interest.

## 📌 Formula

Simple Interest (SI) = (Principal × Rate × Time) / 100

## ✨ Features

- Calculates simple interest from user-provided principal, rate, and time
- Displays the total amount (Principal + Interest)
- Input validation for numeric values
- Clean, easy-to-read output

## 🚀 How to Use

1. Clone the repository:
   git clone https://github.com/<your-username>/simple-interest-calculator.git
2. Open the project folder.
3. Run the script or open the HTML file in a browser.
4. Enter the Principal, Rate, and Time when prompted.
5. View the calculated Simple Interest and total amount.

## 🧮 Example

Input:
- Principal = 10000
- Rate = 5
- Time = 2

Output:
Simple Interest = (10000 × 5 × 2) / 100 = 1000
Total Amount    = 10000 + 1000 = 11000
